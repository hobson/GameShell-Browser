Mission goal
============

Go to the top of the main tower of the castle and create a keg of cider
using a Python script.

Two presses are waiting for you there:

  cider_press.py
    A short, simple script -- just run it, no arguments needed.

  royal_cider_press.py
    A fussier press: it only works on the real ``barrel_of_apples`` from
    the castle's Cellar (it checks the barrel's signature), so you'll
    need to fetch the barrel first.

Either one completes the mission.

Steps (for royal_cider_press.py):
  1. Navigate to the castle's Cellar and find the ``barrel_of_apples`` file.
  2. Move (``mv``) the ``barrel_of_apples`` file to the top of the tower.
  3. Navigate to the top of the tower using ``cd``, if you aren't there
     already.
  4. Run the command: ``python royal_cider_press.py``
  5. This will create a file called ``keg_of_cider.txt`` with cider inside!

Or, more simply: ``cd`` to the top of the tower and run
``python cider_press.py``.


Useful commands
===============

cd LOCATION
  Move to the given location.
  Remark: ``cd`` is an abbreviation for "change directory".

pwd
  Show the path to your current location.
  Remark: ``pwd`` is an abbreviation for "print working directory".

ls
  Show a list of locations that are currently accessible.
  Remark: ``ls`` is an abbreviation of "list".

mv SOURCE DESTINATION
  Move (or rename) SOURCE to DESTINATION.
  Example, from inside the Cellar: ``mv barrel_of_apples
  ../Main_tower/First_floor/Second_floor/Top_of_the_tower`` moves the
  barrel up to the top of the tower (Cellar and Main_tower are both
  directly inside Castle).

python SCRIPT
  Run a Python script.
  Example: ``python cider_press.py`` runs the cider_press.py script.
  Run ``python royal_cider_press.py --help`` to see its options, including
  where the barrel_of_apples file lives.

gsh check
  Check if the mission objective has been achieved.

gsh reset
  Restart the mission from the beginning.


Remarks
-------

UPPERCASE words appearing in commands are meta-variables: you need
to replace them by appropriate (string) values.

Most filesystems treat uppercase and lowercase characters
differently. Make sure you use the correct path.
