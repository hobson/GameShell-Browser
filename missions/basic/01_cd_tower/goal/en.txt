Mission goal
============

Go to the top of the main tower of the castle and create a keg of cider
using the Python script ``cider_press.py``.

Steps:
  1. Navigate to the top of the tower using ``cd``
  2. Run the command: ``python cider_press.py``
  3. This will create a file called ``keg_of_cider.txt`` with cider inside!


Useful commands
===============

cd LOCATION
  Move to the given location.
  Remark: ``cd`` is an abbreviation for "change directory".

pwd
  Show the path to your current location.
  Remark: ``pwd`` is an abbreviation for "print working directory".

ls
  Show a list of locations that are currently accessible.
  Remark: ``ls`` is an abbreviation of "list".

python SCRIPT
  Run a Python script.
  Example: ``python cider_press.py`` runs the cider_press.py script.

gsh check
  Check if the mission objective has been achieved.

gsh reset
  Restart the mission from the beginning.


Remarks
-------

UPPERCASE words appearing in commands are meta-variables: you need 
to replace them by appropriate (string) values.

Most filesystems treat uppercase and lowercase characters 
differently. Make sure you use the correct path.
